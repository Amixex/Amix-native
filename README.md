# Amix — нативное приложение (этап 2: каркас)

Kotlin + Jetpack Compose + Material 3, Hilt, Room, Navigation Compose, MediaPipe (модель внутри APK).

## Что есть в этом этапе
- Тема из токенов веб-версии (`ui/theme/Color.kt`, `Type.kt`, `Theme.kt`).
- Оболочка: верхняя панель (логотип, RU/EN), боковое меню, навигация по 5 экранам.
- Строки RU/EN перенесены из веб-версии (`res/values`, `res/values-en`), язык переключается в приложении.
- История чатов в Room (только на устройстве).
- ИИ: модель из APK копируется во внутреннюю память один раз, дальше запускается без интернета.

## Что пока заготовка
Анимация «чёрной дыры», значок-призрак, точная вёрстка экранов, вход, промокоды, дневной лимит,
оплата, документы. Это следующие этапы.

## Как обновить репозиторий на GitHub
Загрузите папку `app` и файл `build.gradle.kts` (Add file → Upload files). Файлы с тем же путём заменятся.
Старый файл `app/src/main/java/com/amix/tutor/ui/Theme.kt` больше не нужен: его можно удалить, но он не мешает.
Файл `.github/workflows/build.yml` менять не нужно. APK появится в Releases.
